Authentication

The CrownScore workflow starts with the Authentication Module. It asks you to choose between logging in or signing up.

Login

  1. Choose Login and enter your username and password.
  2. If the credentials are correct, you get access to the Main System.
  3. If the credentials are wrong, you can try again. ↻ Loop
  4. Forgot your password? Start the Forgot Password process below.

Sign-up

  1. Choose Sign-up and enter a username and password.
  2. Pick a security question from the list, or write your own, and type your security answer.
  3. If the input is invalid, the system shows a message and repeats the request until the data is correct. ↻ Loop
  4. Once valid information is given, you move directly into the Main System.

Forgot Password

  1. Enter your username.
  2. The system finds your account and shows the security question you saved. It is read-only, so you can't change it here.
  3. Type your security answer and your new password.
  4. Once the password is updated, you return to the login screen.

Main System

Profile

  1. Choose Profile to see your username, your role (Admin or Judge) and the total number of pageant sessions you have attended.
  2. Open the Admin Events tab to see every room you created: its name, creation date and status (Active or Completed), with quick links to Manage a room or View results.
  3. Open the Judged Events tab to see every room where you were a judge, your scoring status (Submitted or In progress) and when you were last active.
  4. Use the search box to find a room by name or code, then go back to the main dashboard.

Main System

Room

Choosing Room begins the judging process, depending on your role.

👑 Admin

  1. Start by creating a room: enter the room name, the number of judges and a room access password. The Room ID is generated for you.
  2. Add your categories (for example, Production Number) and the sub-criteria under each one with their weights. The weights in each category must total exactly 100%.
  3. Add your candidates: candidate number, name and the title or group they represent.
  4. Share the Room ID and password with your judges, then click Start Judging.
  5. Monitor the live score tracking until all judges have submitted their scores. ↻ Loop
  6. Once all scores are in, the system automatically calculates the results.

⚖️ Judge

  1. Select Join Room and enter the Room ID, choose your judge slot and enter the room password.
  2. If the password is wrong, you can keep entering it until it is accepted. ↻ Loop
  3. Once validated, you join the room and see the candidates for that room only.
  4. Score each candidate on every sub-criterion. A score can't go above that sub-criterion's maximum.
  5. Submit your scores when you are done.

🏆 Winners & Rankings

After all scores are submitted, both the Admin and the Judges are taken to a shared screen that shows the winners, the category awards and the full rankings. Use Download Official Report to save the tabulation as an Excel file or a printable PDF. This screen stays open until you choose to leave. ↻ Loop When you leave, you return to the Main System.

6

How it works

How Scores Are Calculated

  1. Sub-criterion score: each judge scores a candidate on every sub-criterion, for example Pose 30%, Mastery 30%, Self-Introduction 30% and Audience Impact 10%.
  2. Category score: the system adds up all the sub-criterion scores of that category. A category is worth 100 points in total.
  3. Final score: the category scores are combined, using each category's weight, into the candidate's overall score. The highest final score ranks first.
